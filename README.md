# The Brilliant Calc 🧠✨

> *"Confidently wrong, every single time."*

The Brilliant Calc is a sleek, OLED-dark mobile calculator designed to troll anyone using it. Under the hood, it calculates the exact math, then adds an unpredictable, clever little jitter so the answer is always *almost* right—driving your friends crazy when $2 + 2 = 3$ or $5$!

---

## ✨ Features

* **🎯 Clever Troll Engine:** Automatically nudges small sums and dynamically jitters larger calculations by $0.3\%$ to $2.5\%$ so it always looks convincing.
* **🤫 Secret Panic Mode:** Triple-tap **"The Brilliant Calc"** title at the top left to instantly switch to 100% real, correct math (indicated by a subtle dot color shift). Perfect for when you need to prove it works!
* **📜 Calculation History:** Tap the clock icon to review past calculations or tap any item to instantly reload it.
* **📳 Toggleable Haptics:** Features gentle feedback with an easy toggle switch inside the About menu to turn vibrations on or off.
* **📱 PWA Ready:** Fully installable as a native app on your phone with zero browser address bars.
